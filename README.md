# Hanaa Morsi - Portfolio

Open `index.html` in a browser to preview.

To publish on GitHub Pages:
1. Create a repository named `hanaamohmad.github.io` (or any name).
2. Upload everything in this folder (index.html, css, images, assets).
3. Settings > Pages > Deploy from branch (main, root).

To update a project: replace its image in `images/` and edit the card in `index.html`.
